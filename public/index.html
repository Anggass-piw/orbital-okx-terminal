Pasang Orbital

Pasang dari URL HTTPS halaman ini. Aplikasi memakai katalog perpetual yang sama dengan versi web; memasang tidak mengaktifkan order nyata.

Android / Chrome: menu ⋮ → Instal aplikasi atau Tambahkan ke layar utama.

iPhone / iPad: buka di Safari → Bagikan → Tambahkan ke Layar Utama.

Desktop Chrome / Edge: gunakan ikon instalasi di bilah alamat atau menu browser → Instal aplikasi.

Shell bisa dibuka offline setelah dimuat. Harga pasar tetap memerlukan internet; data paper disimpan per perangkat.
